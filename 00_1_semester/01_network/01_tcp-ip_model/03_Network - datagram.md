#### Nat - Network Address Translation
A method of mapping a networks public IP address to an IP address on the network

#### Ping
A way to test the reachability time of a host on a IP network. It measures the round trip from the originating host to the destination and back. 

#### Traceroute
Tracks how data travels on the internet from a source to a destination
