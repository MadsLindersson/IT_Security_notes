#### Sack
An option in TCP used to make the receiver cache all of the packets received and if there is a packet loss, the transmitter only has to send that one packet and do not need to start over from where the first packet got lost. 

#### MSS - Maximum Segment Size
This is the maximum size of the data that can be sent in one packet without the header.
