### Politikker
Et regelsæt omkring hvordan man gør tingene f.eks. regler for opsætning af password
- Hvad skal vi beskytte
- Hvem er allowed
- what you are allowed to
- hvordan det vedligholdes

Vigtigt det er skrevet ned

hvilke politikker og hvem der bestemmer dem kommer an på hvilket firma man har og hvilket data der skal beskyttes. 
Det kan være ISO standarder eller GDPR.

Dækker typisk over:
- adgangsregler
- software installationsrettigheder
- data permissions
- Recovery failure - hvad skal der gøres når det går galt

**"Anything not explicitly permitted should be restricted"**

Politikker har typisk sub politikker

**XOR**
True False = True
True True = False
False true = True
False False = False




#### Opgaver

##### Best practices - Find out what a real security policy looks like
1. Politik om adgang - hvem der har adgang til hvad og hvor meget
	- Hvis en har adgang til for meget og bliver hacket så får hackeren det hele i stedet for at det kun bliver en lille del fordi en person har adgang til for meget.
2. Politik om passwords
3. Politik om konfiguration af system, applikation eller cloud service 
	- for at undgå miskonfiguration der leder til sikkerhedshuller
4. Politik omkring downloads
	- Undgå at der er nogen der downloader malware
5. management responsibilities
	- Politikker omkring lederskabet overholder sikkerhedsregler således at medarbejder også overholder sikkerhedsregler
