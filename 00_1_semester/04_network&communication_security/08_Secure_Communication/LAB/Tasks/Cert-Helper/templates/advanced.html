Trust Guidance

Only trust the CA created for this lab. Remove it after the exercise if no longer required.

Kali / Ubuntu

sudo cp ca.cert.pem /usr/local/share/ca-certificates/student-ca.crt
sudo update-ca-certificates

Windows

Import ca.cert.pem into Trusted Root Certification Authorities. Administrator privileges may be required.

certutil -addstore -f Root ca.cert.pem

macOS

Use Keychain Access to import the certificate and set it to Always Trust for the lab.

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ca.cert.pem

Firefox

Open Firefox certificate settings and import ca.cert.pem as a trusted certificate authority for the lab.
