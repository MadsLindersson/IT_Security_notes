Step 1 · Understand Certificate Authority trust

Creating or signing a certificate does not make it trusted. Trust must be configured separately in an operating system or browser, and this lab cannot verify that configuration.

Copy the CA certificate to the local trust directory, then refresh the trust store.

sudo cp ca.cert.pem /usr/local/share/ca-certificates/student-ca.crt
sudo update-ca-certificates

Import ca.cert.pem into Trusted Root Certification Authorities. Administrator privileges may be required.

certutil -addstore -f Root ca.cert.pem

Open Keychain Access, import the CA certificate, then set trust to Always Trust for this lab CA.

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ca.cert.pem

Open Firefox certificate settings, import ca.cert.pem, and allow it to identify websites if required for the lab.

Lab safety: Only import the CA created for this exercise, and remove it when finished. Do not trust certificates you do not recognize.
